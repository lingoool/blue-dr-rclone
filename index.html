blue-dr-rclone

blue-dr-rclone is a private Google OAuth client used by one person for their own computer backups. It is not a public service and does not offer sign-ups.

It lets the open-source tool rclone store encrypted backup files in the owner's own Google Drive. The backups are encrypted on the owner's computer with restic before they are uploaded.

It requests only the drive.file permission, so it can access only files it created itself, not anything else in Google Drive.
